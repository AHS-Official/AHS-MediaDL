## 📁 هيكل المشروع (Project Structure)

```text
AHS-MediaDL/
├── assets/                    # أصول التطبيق والأيقونات الرسومية
│   ├── icon.ico               # أيقونة البرنامج الرسمية
│   └── icons/                 # 31 أيقونة فيكتور SVG ملونة ديناميكياً
├── core/                      # النواة البرمجية والتحميل الخلفي
│   ├── __init__.py
│   ├── downloader.py          # خيوط الفحص والتحميل الخلفية (yt-dlp)
│   └── ffmpeg_handler.py      # معالجة ودمج الترجمات والصوت والصورة (FFmpeg)
├── data/                      # تخزين البيانات والإعدادات المحلية (تُنشأ تلقائياً) 
│   ├── history.json           # سجل التنزيلات المكتملة
│   └── settings.json          # إعدادات التطبيق وتفضيلات المستخدم 
├── gui/                       # واجهة المستخدم الرسومية (PyQt6) 
│   ├── __init__.py 
│   ├── widgets.py             # جسر استيراد وتصدير المكونات والواجهات
│   ├── main_window.py         # النافذة الرئيسية، إدارة القوائم، والتحكم بالخلفية
│   ├── components/            # العناصر الرسومية المخصصة والمستقلة
│   │   ├── __init__.py 
│   │   ├── buttons.py         # الأزرار التفاعلية ومفاتيح التشغيل المتحركة
│   │   ├── cards.py           # كروت التحميل الفردية والتاريخ وقوائم التشغيل
│   │   ├── common.py          # العناصر المشتركة (النصوص الطويلة، الشاشات الفارغة)
│   │   └── dialogs.py         # النوافذ المنبثقة والتوست الذكي وصندوق التجميع
│   └── pages/                 # صفحات التطبيق الرئيسية 
│       ├── __init__.py 
│       ├── home_page.py       # الصفحة الرئيسية (فحص الروابط وتخصيص الجودة)
│       ├── downloads_page.py  # صفحة إدارة التحميلات النشطة والانتظار 
│       ├── history_page.py    # صفحة سجل التنزيلات المكتملة
│       └── settings_page.py   # صفحة الإعدادات الشاملة للتطبيق
├── utils/                     # الأدوات المساعدة والمحركات الجانبية
│   ├── __init__.py
│   ├── helpers.py             # وظائف النظام (تنظيف المسارات، تلوين الأيقونات، تحويل LRC) 
│   ├── theme.py               # محرك التصميم الديناميكي (QSS) للثيمات والخطوط والتكبير 
│   └── locales/               # محرك الترجمة واللغات المتعددة 
│       ├── __init__.py        # معالج اللغات الفعال وتوليد نصوص الواجهة 
│       ├── strings_ar.py      # ملف اللغة العربية (ترميز UTF-8) 
│       └── strings_en.py      # ملف اللغة الإنجليزية 
└── main.py                    # نقطة الانطلاق الرئيسية للتطبيق والمستمع الخلفي
